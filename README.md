Basic C# implementation of the popular game Plants-Vs-Zombies.
<img width="392" height="220" alt="image" src="https://github.com/user-attachments/assets/92fbf724-7b95-4bc1-acc9-fb8c163b374c" />

An image taken from the actual game produced by PopCap Studios

The game is set in a post-Zombie apocalypse time. The player has to defend their house by teaming up with an army of aggresive plants who destroy every zombie that comes their way. Our implementation uses C# for the programming aspect and winforms for the visuals. Here are the features from the game that we implemented.
![Screenshot 2026-01-05 170035](https://github.com/user-attachments/assets/1c891d18-7700-454e-a15a-98d2fd4384a2)


The game starts with displaying a main menu with options to start a new game, see the levels, or exit the game.
![Screenshot 2026-01-05 170415](https://github.com/user-attachments/assets/cd4cb6a8-1445-43ab-9c60-ca4e8562bada)
